# Simple Interest Calculator

A lightweight, efficient command-line and programmatic tool designed to calculate simple interest based on principal amount, annual interest rate, and time duration.

## Mathematical Formula

Simple interest is calculated using the standard formula:

$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
* **$P$** = Principal amount (initial investment or loan amount)
* **$R$** = Annual interest rate (in percentage)
* **$T$** = Time period (typically expressed in years)

---

## Features
* Calculates total interest earned or owed over a given timeframe.
* Computes the final total amount (Principal + Interest).
* Validates user inputs to prevent negative values or division errors.
