# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome. We appreciate your help in improving this project!

## How to Contribute

### 1. Reporting Bugs
If you encounter a bug, please open an issue on GitHub. Provide as much detail as possible to help us diagnose the problem:
* A clear and descriptive title.
* Steps to reproduce the issue.
* Expected behavior vs. actual behavior.

### 2. Suggesting Enhancements
Have an idea for a new feature or improvement? Open an issue to discuss your proposal before writing code.
